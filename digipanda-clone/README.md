# digiPanda Website Clone (Pixel-Perfect Replica)

A pixel-perfect, fully interactive replica of [digiPanda Consulting](https://digipanda.co.in/).

## 🚀 Features & Highlights
- **Exact Design Tokens**: Sleek dark theme (`#000000` / `#141414`), electric neon green highlights (`#86c443`), glassmorphic panels, glowing badges, and custom typography.
- **Interactive Header & Mega Menu**:
  - Sticky blurred header.
  - 4-column dropdown mega menu for **Services** (AI Services, Design, Development, Marketing).
  - Dropdown menu for **Products**.
  - Animated "Let's Talk" Panda CTA button with hover slide effects.
  - Mobile responsive hamburger menu drawer.
- **Dynamic Hero Section**:
  - macOS window card with red/yellow/green control dots.
  - Animated blinking eyebrow indicator badge.
  - Rotating animated headline ("Marketing Boost", "AI Automation", "High Conversion", "Scale & Dominate").
  - Overlapping avatar stack for "Our Trusted Clients" with a 1.5K+ badge.
  - Interactive "Our Products" dashboard panel with live stats (+182%), animated bar visualizer, and tab switcher (`Upranke`, `Svaarico`, `AI Automation`).
  - Metric cards: "10Y+ Experience" and "1200+ Global Clients".
- **Infinite Marquee Ticker**: Continuous horizontal scrolling service banner.
- **Video Banner Showcase**: "We Don't Just Use AI Tools, We Build Them" with video banner styling and rounded aesthetics.
- **Full-Stack Growth Services Section**:
  - AI Services spotlight: AI Automation, AI Agents & Chatbots, Upranke, Svaarico, AI Content Studio, GEO.
  - 4 Process Pillars: `01 Discovery`, `02 Design`, `03 Development`, `04 Marketing`, with service pill tags and direct CTAs.
- **Clients Logo Grid**: Realme, USHA, Zee TV, Cuckoo, DID, DBC, Apollo, NDTV, Mojarto, Sailax, ODA, plus circular explore button.
- **Interactive Case Studies Carousel**: USHA Silai, Cuckoo, IDEE Eyewear, HieStyle, Dekoder, Tisva, Give India, Dance India Dance, Theta Gainers, Mirrorwalla with navigation controls.
- **Testimonials Slider**: Client feedback cards with quotes, author names, company badges, and navigation arrows.
- **Expandable FAQ Accordion**: 7 Q&A items answering key client concerns with smooth open/collapse transitions.
- **Project Inquiry Contact Form**: Dual-column section with full contact form and "Driven by Trust" client logo badge grid.
- **Footer & Global Offices Bar**: Live international time clocks (India, Australia, Dubai, Netherlands), full multi-column sitemap, partner badges (Shopify, Meta, Google Partner), and floating digiPanda AI assistant widget.

## 🛠️ Getting Started

### 1. Run the Development Server
```bash
cd "e:\Qala Labs\Website\digipanda-clone"
npm run dev
```

The site will be available at `http://localhost:5173`.

### 2. Build for Production
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
